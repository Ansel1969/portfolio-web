VR まちがい探し

絵本『ミッケ！』の世界に入り込んだような、おもちゃ部屋を舞台にした3次元空間間違い探しVR体験

デバイスMeta Quest

Overview

概要

紙面から空間へ。従来の「間違い探し」をVRの3次元インタラクションへと拡張し、新たな体験価値を創出するコンテンツ。 絵本『ミッケ！』のような、おもちゃが溢れた部屋の中に実際に入り込んで、周囲を見回しながら間違いを探す没入感を実現した。

2つの空間（正解・不正解）を用意し、VR空間内でオブジェクトを掴んで選択するインタラクションで間違いを探す設計。 ゲームプランナーとしての仕様設計から、メインプログラマーとしてのシステム実装まで一貫して担当した。

Technical Highlight

設計上の工夫

ObjectController.cs

オブジェクト自身に「まちがい」の判定ロジックを持たせる設計。 ホバー時に MaterialPropertyBlock で色を薄く変化させる視覚的フィードバックを実装し、 メモリリークを回避（shared material を変更しない）。 正解・不正解の結果のみを GameFlow.cs に通知する責務の分離。

GameFlow.cs

ゲーム全体の進行を一元管理するコントローラークラス。 ObjectController からの通知を受け取り、サウンド再生・UI遷移・パーティクル再生などを指示。 コルーチンによる非同期ゲーム進行で、タイマーやカウントダウン演出も管理。 

// ObjectController.cs — ホバー時のマテリアル変更（メモリリーク回避）
public void ifHover()
{
    if (gameFlow.inGame)
    {
        rend.GetPropertyBlock(M_propBlock);
        M_propBlock.SetColor("_EmissionColor", emitColor);
        rend.SetPropertyBlock(M_propBlock);  // shared material を汚さない
    }
}

public void ifUnHover()
{
    if (gameFlow.inGame)
    {
        rend.GetPropertyBlock(M_propBlock);
        M_propBlock.SetColor("_EmissionColor", Color.black);
        rend.SetPropertyBlock(M_propBlock);
    }
}
